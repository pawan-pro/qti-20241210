Bias-Free Engineering

Most backtests fail due to look-ahead bias in normalization.

  • Expanding Window Z-Scores:
    Statistics are calculated using only data available up to time t. We never normalize using the future mean.
  • Publication Lags:
    Macro data (CPI, GDP) is explicitly lagged by 1 month in the feature set to match real-world release schedules.

Production Inference Logic

Core Python implementation extracted from Week 10.


def _get_predicted_regime(self, date: pd.Timestamp) -> int:
    # 1. Point-in-Time Lookup (asof)
    # features_df is already Lagged and Z-Scored via Pipeline
    feature_features = self.features_df.asof(date)
    
    # 2. Fail-Safe: Default to Cash (Regime 2) if data missing
    if feature_features is None or feature_features.isnull().all():
        return 2 
    # 3. Inference (Low Latency)
    feature_vector = feature_features.values.reshape(1, -1)
    # self.prediction_model is the pre-trained XGBoost artifact
    predicted_regime = self.prediction_model.predict(feature_vector)[0]
    
    return int(predicted_regime)
